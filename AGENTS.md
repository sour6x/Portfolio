# Portfolio frontend guidance

Use only the official project-local frontend skills from Anthropic and OpenAI:

- `.agents/skills/frontend-design/SKILL.md`
- `.agents/skills/frontend-app-builder/SKILL.md`

Read `DESIGN.md` for the established visual direction and typography tokens. Preserve the user's PCB theme, text-free animated chip, large personal greeting, project order, and alternating desktop project images. Keep body copy at least 16px, metadata generally at least 13px, and maintain strong text contrast. Respect reduced-motion preferences and keep controls keyboard accessible.

For small refinements within this existing design, use the existing-system exception to new Image Gen concepting. Broader redesigns should follow the skills' full concept workflow. Do not introduce community skills or external design services without a user request.
